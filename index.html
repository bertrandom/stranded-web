Johnny Castaway is still stranded.

Sierra's 1992 screen saver, playing live right here: same island, same story, a new day of it every day. Put him on a Raspberry Pi and he'll live on your wall.

Make a Johnny screen

stranded-pi

A Raspberry Pi that does one thing: keep Johnny company.

stranded-pi turns a Raspberry Pi into a dedicated Johnny Castaway screen. Plug it into a TV or a spare monitor and it plays full screen from the moment it boots, with no desktop, mouse or keyboard. A web page on your network lets you run it from your phone.

  • The whole story

    Fishing, building the raft, Mary, Suzy, the Lilliputians: every scene of the original, picked the way it picked them. The story moves on a day at a time, over eleven days.

  • Made for widescreen

    Nothing gets stretched. On a 16:9 TV, the ocean and sky carry on to the edges of the screen, and clouds, boats and Johnny go there too.

  • Sleeps at night

    Night mode pauses Johnny and turns the display off between the hours you pick. It can put a TV in standby over HDMI-CEC, and wakes everything in the morning.

  • A remote in your pocket

    Open the Pi's address in a browser for a live preview, play and pause, skipping scenes, the night schedule and settings. There's a JSON API too.

  • Keeps itself current

    Updates to the latest stranded release with one tap on the web page. Reboot and shut down from there too.

  • Light on hardware

    No desktop underneath: it draws straight to the screen through KMS/DRM, on anything from a Pi Zero 2 W to a Pi 5.

Set one up

Two ways to get Johnny onto a Pi.

Flash a ready-made SD card

The image is Raspberry Pi OS Lite (64-bit) with stranded preinstalled. Build it with Docker, on a Mac with Apple Silicon or any machine that has it:

git clone https://github.com/bertrandom/stranded-pi
cd stranded-pi
./image/build-docker.sh
  1. In Raspberry Pi Imager, open App Options and set Content Repository to the repo.json in image/out.
  2. Choose your Pi, then Stranded as the operating system, and your SD card.
  3. Set the hostname, Wi-Fi and a password, and write the card.

On first boot, the Pi applies your settings and starts Johnny. His web page is at http://<hostname>/.

Or set up a Pi you already have

On a Pi running Raspberry Pi OS Lite (64-bit) Trixie, copy over the setup script and run it:

scp setup.sh <your Pi>:
ssh <your Pi> sudo ./setup.sh

It installs the latest stranded release, fetches the game's data files, writes the default settings and starts Johnny. Run it again any time to update. It keeps your settings.

What you need

  • A Raspberry Pi Zero 2 W, 3, 4 or 5
  • A microSD card and a power supply
  • A screen with HDMI: a TV, a monitor, a little display

The full details, including the API, are in the stranded-pi README.

About

An island, kept afloat.

Johnny Castaway was made by Dynamix and published by Sierra in 1992, as a screen saver for Windows 3.1 that told a story over weeks. What plays here is stranded, built on Jérémie Guillaume's open source engine Johnny Reborn. It was ported to TypeScript for this page, which draws every frame on a canvas from the original game's data.

Thanks to Hans Milling for Johnny Castaway Open Source, to Alexandre Fontoura for castaway, and to everyone who worked out how the original works. Johnny Castaway belongs to its rights holders. This is a fan project, with no ties to them.
